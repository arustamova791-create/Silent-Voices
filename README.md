# Səssizlərin səsi

Адаптивный сайт социальной инициативы помощи бездомным животным в Азербайджане. Интерфейс переключается между азербайджанским и русским языками.

## Запуск локально

Нужен Node.js 22 или новее (сервер использует встроенный модуль SQLite). Один раз установите зависимости:

```sh
npm install
```

Затем откройте два окна Terminal в папке проекта.

В первом окне запустите локальный API:

```sh
npm run api
```

Во втором окне запустите сайт:

```sh
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`). Тестовая панель волонтёра находится по адресу `http://localhost:5173/volunteer-panel`; она доступна только в dev-режиме и не включается в production-сборку.

SOS-заявки и история статусов сохраняются в `data/sos.sqlite`, фото — в `data/photos/`. Эти данные остаются на этом компьютере и исключены из Git. API слушает только localhost на порту 3001; Vite проксирует запросы к нему. Чтобы сохранить заявки между запусками, не удаляйте папку `data/`.

Для production-сборки используйте `npm run build`.

Фото загружаются с Unsplash, поэтому для их отображения требуется интернет. Истории и контакты на странице демонстрационные. Платежи не подключены.
