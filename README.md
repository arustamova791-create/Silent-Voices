# Səssizlərin səsi

Адаптивный сайт социальной инициативы помощи бездомным животным в Азербайджане. Интерфейс переключается между азербайджанским и русским языками.

## Запуск локально

Нужен Node.js 22 или новее (сервер использует встроенный модуль SQLite). Один раз установите зависимости:

```sh
npm install
```

Затем откройте два окна Terminal в папке проекта.

В первом окне запустите локальный API:

```sh
npm run api
```

Во втором окне запустите сайт:

```sh
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`). Тестовая панель волонтёра находится по адресу `http://localhost:5173/volunteer-panel`; она доступна только в dev-режиме и не включается в production-сборку.

SOS-заявки и история статусов сохраняются в `data/sos.sqlite`, фото — в `data/photos/`. Эти данные остаются на этом компьютере и исключены из Git. Локально API использует порт 3001; Vite проксирует запросы к нему. Чтобы сохранить заявки между запусками, не удаляйте папку `data/`.

Для production-сборки используйте `npm run build`. Команда `npm start` запускает Node-сервер: он обслуживает сборку из `dist/` и API по адресу `/api`. Render передаёт порт через `PORT`; локально сервер по-прежнему использует `API_PORT` или порт 3001.

## Развёртывание на Render

Создайте **Web Service** для этого репозитория со следующими настройками:

- **Language:** Node
- **Build Command:** `npm ci && npm run build`
- **Start Command:** `npm start`
- **Environment:** `NODE_VERSION=22`

Сервер слушает `0.0.0.0` и порт из `PORT`, а также обслуживает frontend и SOS API на одном домене. Чтобы SOS-заявки и фотографии сохранялись между перезапусками и развёртываниями, добавьте к Web Service **Persistent Disk** с **Mount Path** `/var/data` и задайте переменную `SOS_DATA_DIR=/var/data`. Без диска Render может удалить SQLite-базу и фотографии при новом развёртывании.

Фото загружаются с Unsplash, поэтому для их отображения требуется интернет. Истории и контакты на странице демонстрационные. Платежи не подключены.
